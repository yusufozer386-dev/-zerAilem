# -zerAilem CloudStream Repo

Kişisel CloudStream eklentileri deposu

## Kurulum

1. CloudStream uygulamasını açın
2. Ayarlar → Kaynaklar → Repo Ekle
3. Aşağıdaki bağlantıyı yapıştırın:
   ```
   https://raw.githubusercontent.com/yusufozer386-dev/-zerAilem/main/özer%20ailem1.json
   ```

## Eklentiler

Bu repoda CloudStream için özel eklentiler bulunmaktadır.

### Özellikler

- YouTube Extension
- Diğer eklentiler eklenecek

## Geliştirme

Yeni eklentiler eklemek için:

1. Eklenti dosyasını oluşturun
2. `/builds` branch'ine push edin
3. `plugins.json` dosyasını güncelleyin
